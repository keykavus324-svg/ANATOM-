# Free Anatomy Quiz integration

- Entry: `#/quizler`; stable detail route: `#/quizler/<catalog-id>`.
- Catalog: `src/quizCatalog.js`. 159 links across seven categories. Turkish labels are navigation metadata; quizzes remain in English.
- Link source pages: generalterminology.html, skeletalsystem.html, muscularsystem.html, internalorgans.html, surfaceanatomy.html, senses.html, brain.html, reproductivemain.html. Checked with the page retrieval tool on 2026-10-15. This is a curated index, not a claim to reproduce all 200+ quizzes, therapy resources or every physiology series.
- No source question bank, images, answer keys or scripts are copied or proxied. No claim of publisher permission, partnership or open licensing is made.
- The embedded page is only requested after the visitor starts the preview. Before that there are no publisher requests or remotely loaded thumbnails.
- **Verified publisher engine (2026-10-15, from the publisher's own `quizrun.js` / `quizrun2.js`):** question advance happens in `nextQuestion()` as `top.location = <quiz page>?questNum=N&cor=N` — a full reload of the **top-level browsing context**; quiz state lives only in the URL query. Wrong answers show an in-page feedback panel and never advance; the "select an answer" prompt is a `window.alert`. Consequences: (1) inside our sandboxed iframe the advance click is silently blocked by the browser (no `allow-top-navigation`), (2) the alert needs `allow-modals`, (3) `randQuiz` reshuffles the remaining questions on every load, so deep-linking `?questNum=` from outside cannot preserve the publisher's question set or score and is therefore not used.
- Native embedding does not bypass frame protection. Publisher CSP/frame policies, connectivity or browser settings can block it. An always-visible direct link opens the identical source quiz in a separate tab.
- Because in-frame advance is impossible without proxying (which this project refuses), the always-working source view is the **primary** action on the consent screen (“Quizi kaynağında çöz”) and again as a persistent hint card above the embedded preview (“Sorular bu pencerede ilerlemiyor mu?”). The embed is labelled a first-question preview in the consent copy, the status line and the card.
- Browser cross-origin protections prevent reading answers, scores and the iframe's current URL. A load event is not evidence of a usable quiz. The UI never claims automatic results sync or quiz completion. “Çalıştım” is a self-reported local study mark. Resume only reopens the source URL, not a saved question.
- Local preferences use dedicated keys, validate IDs and tolerate unavailable storage. No changes to existing practice bank, saved lesson notes or exam scoring.
- `sandbox` restricts top navigation while permitting source scripts, origin, forms, publisher alerts (`allow-modals`, so the engine's “select an answer” feedback is visible in the preview) and user-opened windows. Handing the whole ANATOMİ tab to the publisher on every question advance (`allow-top-navigation-by-user-activation`) was considered and rejected: a silent full-page takeover from an embedded pane is a worse failure mode than a guided new-tab path.

## Validation

- Unit tests verify link origins/case, unique IDs, lesson mappings, route round trips, filters and preference validation.
- Browser tests cover consent-gated iframe insertion, direct-link fallback, reload, browser back, favorites, self-reported study marks, empty states, mobile overflow, invalid routes, unavailable storage and the original practice entry.
- External frames are mocked in automated UI tests. Live third-party iframe compatibility is **not verified** in this sandbox, whose browser network access is restricted. However, the advance mechanism above is verified from the publisher's own script source (archived copies of `quizrun.js` and `quizrun2.js`): in-frame question advance cannot work for this publisher, independent of network conditions. No claim that all publisher quiz pages successfully embed is made.
